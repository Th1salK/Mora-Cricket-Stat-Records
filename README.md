Mora Cricket Stats
A stats dashboard I built for our cricket team to track matches, player performances, and career statistics across different formats.

What it does
Dashboard — Quick overview with links to everything
Matches — Add, edit, and delete match records
Players — Manage our squad roster
Batting Stats — Per-player batting numbers (runs, average, strike rate, 50s, 100s, etc.) filterable by match type
Bowling Stats — Per-player bowling numbers (wickets, economy, best figures, 5-wicket hauls) filterable by match type
Career Overview — All-time team stats broken down by format
Player Profiles — Click on any player to see their full batting and bowling history
Stats Entry — Admin-only page to enter match performances
We track stats across 5 formats: Home and Home, Practice, Div 3, Inter Uni, and SLUG.

Tech stack
Next.js
MongoDB with Mongoose
Tailwind CSS
bcryptjs for password hashing
